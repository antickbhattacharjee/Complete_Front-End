# Front-End Development Training Repository

Welcome to the **Front-End Development Training Repository**. This repository is designed for structured classroom training, self-learning, practical assignments, and comprehensive revision. It covers a complete, professional day-wise training program across HTML, CSS, and JavaScript.

## 🚀 Training Program Overview

This curriculum is built on a progressive learning model. Every domain contains a minimum of 10 days of classes that evolve from absolute beginner concepts to advanced, practical web development projects.

The learning methodology strictly enforces:
- **Zero Placeholder Content**: Every file contains real, usable educational material.
- **Practical Learning**: Assignments require actual coding, not just theory.
- **Progressive Difficulty**: Concepts build logically on top of each other.
- **Cross-Domain Integration**: HTML integrates with CSS, which in turn integrates with JavaScript, culminating in full web applications.

## 📚 Curriculum Breakdown

### 1. [HTML Curriculum](./html/README.md)
10 classes covering HTML from beginner document structure to advanced APIs and Semantics, concluding with a fully structured Mini Project.

### 2. [CSS Curriculum](./css/README.md)
10 classes progressing from basic selectors and colors to advanced layouts like Flexbox and CSS Grid, responsive design, and concluding with a Responsive Website Project.

### 3. [JavaScript Curriculum](./js/README.md)
10 classes starting with programming fundamentals, moving deeply into DOM manipulation, event handling, and data fetching, ending with a complete Interactive Web Application.

## ⚙️ Prerequisites & Software Requirements

- **Basic Computer Knowledge**: Understanding of files, folders, and web browsing.
- **Code Editor**: [Visual Studio Code (VS Code)](https://code.visualstudio.com/) recommended.
- **Web Browser**: Google Chrome or Mozilla Firefox (latest versions) with Developer Tools.
- **Extensions**: Live Server (VS Code extension) for live reloading.

## 📂 Folder Structure & Usage

Every day across all domains follows a strict, consistent structure to provide a seamless learning experience:

```text
day-XX/
├── README.md               # Daily objectives, prerequisites, and topics
├── training/
│   ├── concepts.md         # Detailed explanations, syntax, mistakes, notes
│   ├── examples/           # Working code examples (Basic -> Advanced)
│   └── demo/               # Trainer demo files
├── practical/
│   ├── assignment.md       # Tasks assigned for practice (Basic to Real-world)
│   └── starter/            # Starter files for the assignment (if applicable)
└── answers/
    ├── answer.md           # Step-by-step explanations of the solution
    └── solution/           # Fully functional, logical, and runnable code
```

## 🎓 Recommended Learning Sequence

1. **Read `README.md`**: Start each day by understanding the learning objectives and topics.
2. **Study `training/concepts.md`**: Follow the concept explanations, review the syntax, and study the provided examples.
3. **Analyze `examples/`**: Run the example code files in your browser and modify them to see how changes affect the output.
4. **Attempt `practical/assignment.md`**: Complete the tasks starting from Assignment 1 up to the Real-world practical task. Write your code in the `practical/starter/` folder if provided, or create your own files.
5. **Review `answers/`**: Check your work against the provided `answer.md` and the fully working code in `answers/solution/`.

## 👨‍🏫 Trainer/Student Workflow

- **Trainers**: Use the `concepts.md` (which includes Trainer Notes) to guide classroom discussions. Use the `examples/` folder for live coding demonstrations. Assign the `practical/` folder for lab time.
- **Students**: Use the repository as a daily textbook. The "Quick Revision" sections at the end of each `concepts.md` are perfect for exam prep or interview readiness.

Enjoy the journey to becoming a professional Front-End Developer!

# Day 06 Assignment

## Assignment 1: Basic practice
Create an object called `car`. Give it properties for `make` (string), `model` (string), and `year` (number). Log the car's model to the console.

## Assignment 2: Intermediate practice
Add a new property to your `car` object called `isElectric` (boolean). Then, write an `if` statement checking `car.isElectric`. If true, log "Charge the battery". If false, log "Fill the gas tank".

## Assignment 3: Real-world practical task
Process a mock database of employees.
1. Create `script.js`.
2. Create an array called `employees` containing 3 objects.
3. Each object should have: `name`, `department`, and `salary`.
4. Write a `forEach` loop to print out a badge for every employee (e.g., "Jane works in HR and makes $50000").
5. Write a `.filter()` function to create a new array containing only employees in the "IT" department. Log this new array.

# Day 06: Objects & JSON

## Learning Objectives:
- Create JavaScript Objects to group related data.
- Access and modify object properties using dot notation.
- Understand arrays of objects.
- Understand what JSON is and how to parse it.

## Expected Learning Outcome:
You will be able to structure complex, real-world data (like a User Profile or a Product Catalog) entirely in JavaScript.

## Duration:
2.5 Hours

## Prerequisites:
- Variables, Functions, and Arrays.

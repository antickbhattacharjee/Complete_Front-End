# Day 01 Assignment

## Assignment 1: Basic practice
Open Chrome. Right-click anywhere, select "Inspect", and go to the "Console" tab. Type `console.log("Testing 123");` and press Enter.

## Assignment 2: Intermediate practice
Create an `index.html` file. Use an internal `<script>` tag to trigger an `alert("Hello");` when the page loads.

## Assignment 3: Real-world practical task
Setup a clean JS environment.
1. Create `index.html` and `script.js`.
2. Link the JS file to the HTML file properly at the bottom of the body.
3. In `script.js`, write three `console.log` statements:
   - One stating your name.
   - One stating your favorite programming language so far.
   - One calculating math (e.g., `console.log(10 + 5);`).
4. Open the HTML file in the browser and check the Console to verify it worked.

# Day 01: Introduction to JavaScript Fundamentals

## 🎯 Learning Objectives
- Understand what JavaScript is and its role in web development
- Learn how to run JavaScript in browsers
- Master console.log() for debugging
- Understand basic syntax and comments
- Write your first interactive code

## 📊 Difficulty Level
**Beginner** — No prior programming required

## ⏱️ Estimated Duration
**2 hours** (1.5 hours training + 0.5 hours practical exercises)

## 📋 Prerequisites
- Completion of HTML and CSS curricula
- Basic understanding of browser DevTools

## 🔑 Core Topics
1. What is JavaScript and its role in web interactivity
2. The `<script>` tag and where to place it (internal vs. external)
3. console.log() for debugging and output
4. Single-line (//) and multi-line (/* */) comments
5. JavaScript syntax basics
6. The browser console as a REPL environment
7. Errors and debugging strategies

## 📝 Files You Will Create
- `script.js` — Your first external JavaScript file
- `index.html` — HTML pages linked to JavaScript
- Browser console experiments

## 🎓 Suggested Lesson Sequence
1. **What is JS?** (10 min): Explain the HTML (structure) + CSS (style) + JS (behavior) trinity
2. **Placing Script Tags** (10 min): Show why `<script>` goes at bottom of `<body>`
3. **console.log()** (15 min): Open DevTools; type in console; see output
4. **External Files** (10 min): Explain `<script src="app.js"></script>` pattern
5. **Concept Study** (25 min): Follow `training/concepts.md`
6. **Live Demo** (15 min): Show `training/demo/index.html`; interact with console
7. **Practical Lab** (35 min): Complete `practical/assignment.md`
8. **Review** (10 min): Show solutions; discuss debugging tips

## ✅ Practical Assignment Summary
- **Assignment 1**: Create an HTML file with a `<script>` tag that runs `console.log()`
- **Assignment 2**: Link an external `script.js` file and log multiple messages
- **Assignment 3**: Create an interactive page that uses `alert()` and `console.log()` together

## 🎓 Expected Learning Outcome
By the end of this day, you will:
- Understand how JavaScript fits into web development
- Know how to include JavaScript in HTML (external is best)
- Be able to use console.log() for debugging
- Feel comfortable working with the browser console
- Be ready to learn variables and logic

## 📚 Quick Revision Checklist
- [ ] JavaScript = Programming language for web interactivity
- [ ] Link external JS: `<script src="file.js"></script>` at bottom of `<body>`
- [ ] `console.log("text")` prints to the browser console (not to the page!)
- [ ] Open DevTools: F12 or Right-Click → Inspect → Console tab
- [ ] Comments: single line with `//`, multi-line with `/* */`
- [ ] The console is a REPL: you can type code and see results instantly
- [ ] `alert()` shows a popup dialog (use sparingly; prefer console for debugging)
- [ ] Semicolons end statements (JavaScript can insert them, but explicit is better)
- [ ] Always check the console for error messages when debugging
- [ ] Never leave `console.log()` calls in production code

# Day 01: Introduction to JavaScript

## Learning Objectives:
- Understand the role of JavaScript in web development.
- Learn how to link JS to HTML (Internal vs External).
- Use `console.log()` to print messages to the browser console.

## Expected Learning Outcome:
You will be able to write basic JavaScript commands and view their output in the browser Developer Tools.

## Duration:
1.5 Hours

## Prerequisites:
- HTML Document Structure.

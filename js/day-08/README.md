# Day 08: Events and Form Handling

## Learning Objectives:
- Listen to user interactions using `addEventListener`.
- Handle click, input, and submit events.
- Prevent default browser behaviors (like form refreshing).
- Read data from HTML input fields.

## Expected Learning Outcome:
You will be able to build interactive web applications that respond to user clicks and process user input from forms.

## Duration:
3 Hours

## Prerequisites:
- DOM Manipulation (Day 07).

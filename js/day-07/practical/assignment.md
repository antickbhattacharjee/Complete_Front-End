# Day 07 Assignment

## Assignment 1: Basic practice
Create an HTML file with an `<h1>` that says "Hello". In JS, select the `<h1>` and change its text to "Goodbye".

## Assignment 2: Intermediate practice
Add a `<p>` to your HTML with an ID of `msg`. In JS, select it and change its inline style color to red.

## Assignment 3: Real-world practical task
Create a dynamic UI updater.
1. Create `index.html`, `style.css`, and `script.js`.
2. HTML: Create a profile card with an `<img>`, an `<h2>` for the name, and a `<p>` for the bio. Give them all IDs.
3. CSS: Style the card so it looks decent. Create a `.dark-mode` class for the `body` that turns the background black and text white.
4. JS: Select the `<img>`, `<h2>`, and `<p>`.
5. JS: Use `textContent` to inject your own name and bio into the elements.
6. JS: Use `src` to inject a placeholder image URL into the `<img>`.
7. JS: Use `document.body.classList.add('dark-mode')` to forcefully activate the dark theme.

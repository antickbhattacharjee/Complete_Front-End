# Day 07: DOM Manipulation

## Learning Objectives:
- Understand what the Document Object Model (DOM) is.
- Select HTML elements using `querySelector` and `getElementById`.
- Change HTML content, CSS styles, and CSS classes dynamically using JavaScript.

## Expected Learning Outcome:
You will be able to bridge the gap between your JavaScript logic and your HTML interface, updating the screen without refreshing the page.

## Duration:
3 Hours

## Prerequisites:
- JavaScript Objects and Variables.
- HTML Document Structure.

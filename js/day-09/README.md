# Day 09: Local Storage & Fetch API

## Learning Objectives:
- Persist data across page reloads using the browser's `localStorage`.
- Convert JS Objects to JSON strings (and back) using `JSON.stringify` and `JSON.parse`.
- Fetch data from external APIs using `fetch()` and `async/await`.

## Expected Learning Outcome:
You will be able to save user data locally and connect your web applications to real-world internet databases.

## Duration:
3 Hours

## Prerequisites:
- JS Objects, JSON, and DOM Manipulation.

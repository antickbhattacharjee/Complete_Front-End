# JavaScript Curriculum

Welcome to the **JavaScript Training Program**. This 10-day curriculum bridges the gap between static web pages and fully interactive web applications. You will learn core programming logic and how to manipulate the browser dynamically.

## 🎯 Learning Outcomes
By the end of this module, you will be able to:
- Write modern JavaScript (ES6+) using variables, loops, and conditional logic.
- Work with complex data structures like Arrays and Objects.
- Manipulate the Document Object Model (DOM) to change HTML/CSS dynamically.
- Handle user interactions and form submissions using Event Listeners.
- Fetch data from external APIs and manage Local Storage.

## 🛠️ Prerequisites
- Completion of the [HTML Curriculum](../html/README.md) and [CSS Curriculum](../css/README.md).
- Strong understanding of HTML document structure (vital for DOM manipulation).
- Strong understanding of CSS classes and IDs.

## 🚀 Projects
- **Day 10 Project**: You will build a complete "Interactive Weather or To-Do Application". This final project integrates HTML, CSS, and JS. It will fetch data, update the UI dynamically, and store user preferences, serving as a comprehensive capstone for the Front-End training.

## 📖 Recommended Progression
JavaScript introduces programming logic, which can be challenging if you're new to coding. Do not rush through Days 1-6. A strong grasp of loops, functions, arrays, and objects is mandatory before attempting DOM Manipulation on Day 7. Practice heavily in the browser console.

# Day 04 Assignment

## Assignment 1: Basic practice
Write a traditional function called `sayGoodbye` that takes one parameter (`name`). It should `console.log` a goodbye message to that name. Call the function twice with different names.

## Assignment 2: Intermediate practice
Rewrite the exact same function from Assignment 1, but this time use the ES6 Arrow Function syntax (`const sayGoodbye = (name) => { ... }`).

## Assignment 3: Real-world practical task
Create a Temperature Converter.
1. Create `script.js`.
2. Write a function called `celsiusToFahrenheit` that takes one parameter: `celsius`.
3. Inside the function, calculate the Fahrenheit value using the formula: `(celsius * 9/5) + 32`.
4. `return` the calculated value.
5. Outside the function, declare a variable `todayTemp = 25;`.
6. Call your function, passing in `todayTemp`. Store the result in a new variable called `fTemp`.
7. `console.log` the final result using a template literal.

# Day 04: Functions & Scope

## Learning Objectives:
- Define and call JavaScript functions.
- Pass arguments into functions and `return` values.
- Understand modern ES6 Arrow Functions.
- Grasp the concept of Variable Scope (Global vs Local).

## Expected Learning Outcome:
You will be able to write reusable blocks of code that perform specific tasks, keeping your scripts clean and DRY (Don't Repeat Yourself).

## Duration:
2.5 Hours

## Prerequisites:
- JS Variables and Basic Logic.

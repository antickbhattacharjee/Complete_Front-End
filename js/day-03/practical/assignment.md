# Day 03 Assignment

## Assignment 1: Basic practice
Write an `if/else` statement. Declare a variable `temperature`. If it is greater than 30, log "It is hot outside". Otherwise, log "The weather is nice".

## Assignment 2: Intermediate practice
Write a `for` loop that logs the numbers from 1 to 10 in the console.

## Assignment 3: Real-world practical task
Create a FizzBuzz script. 
1. Create `script.js`.
2. Write a `for` loop that runs from 1 to 15.
3. Inside the loop, write `if/else if/else` logic:
   - If the number is exactly equal to 7, print "Lucky Seven!".
   - If the number is greater than 10, print "Greater than ten".
   - Otherwise, just print the number itself.

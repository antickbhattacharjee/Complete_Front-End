# Day 03: Conditions and Loops

## Learning Objectives:
- Use `if`, `else if`, and `else` statements to make decisions in code.
- Understand comparison operators (`===`, `>`, `<`).
- Use `for` loops to repeat blocks of code.

## Expected Learning Outcome:
You will be able to write dynamic scripts that change behavior based on input, and automate repetitive tasks.

## Duration:
2.5 Hours

## Prerequisites:
- JS Variables and Data Types.

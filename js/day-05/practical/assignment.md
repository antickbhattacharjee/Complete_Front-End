# Day 05 Assignment

## Assignment 1: Basic practice
Create an array called `movies` containing 3 movie titles (strings). Log the second movie to the console.

## Assignment 2: Intermediate practice
Use the `.push()` method to add a 4th movie to your array. Then, use a `.forEach()` loop to print out all 4 movies individually.

## Assignment 3: Real-world practical task
Create a "Passed Students" filter.
1. Create `script.js`.
2. Define an array of test scores: `const scores = [45, 80, 65, 92, 30, 75];`
3. Use the `.filter()` method to create a new array called `passedScores` that only contains numbers greater than or equal to 60.
4. Use the `.map()` method on `passedScores` to create a new array called `gradedScores`. Multiply each score by 1.1 (giving a 10% curve).
5. Log the final `gradedScores` array to the console.

# Day 05: Arrays & Array Methods

## Learning Objectives:
- Create and manipulate Arrays (lists of data).
- Access array elements via index.
- Use basic methods (`push`, `pop`).
- Iterate over arrays using modern methods (`forEach`, `map`, `filter`).

## Expected Learning Outcome:
You will be able to store large collections of data and manipulate, filter, or loop through that data efficiently.

## Duration:
3 Hours

## Prerequisites:
- Functions (specifically Arrow functions, which are used heavily in array methods).

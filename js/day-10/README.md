# Day 10: Complete Web App Project

## Learning Objectives:
- Synthesize all JavaScript knowledge acquired over the last 9 days.

You will have built a complex, interactive web application from scratch that handles user input, dynamically updates the UI, and saves data persistently.

3 Hours

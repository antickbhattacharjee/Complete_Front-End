# Day 02: Variables, Data Types & Operators

## Learning Objectives:
- Declare variables using `let` and `const`.
- Understand basic data types (String, Number, Boolean).
- Use arithmetic and assignment operators.
- Combine strings using Template Literals.

## Expected Learning Outcome:
You will be able to store, modify, and calculate data within JavaScript.

## Duration:
2 Hours

## Prerequisites:
- JS Day 01.

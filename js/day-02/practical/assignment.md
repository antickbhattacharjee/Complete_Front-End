# Day 02 Assignment

## Assignment 1: Basic practice
Declare a `const` variable for your birth year, and a `let` variable for your current age. Log them to the console.

## Assignment 2: Intermediate practice
Update your age variable to be one year older. Use a Template Literal (backticks) to log: "I was born in [year] and I am now [age]."

## Assignment 3: Real-world practical task
Build a mini shopping cart calculator.
1. Create `script.js` (and link it to an HTML file).
2. Declare a `const` for an item name (e.g., "Wireless Mouse").
3. Declare a `const` for the item price (e.g., 25).
4. Declare a `let` for the quantity (e.g., 2).
5. Calculate the total cost (price * quantity) and store it in a new variable.
6. Use a template literal to `console.log` a receipt: "You bought 2 Wireless Mouse(s) for a total of $50."
7. Now, change the quantity to 3, recalculate the total, and log the receipt again.

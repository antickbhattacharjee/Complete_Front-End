# Day 01 Assignment

## Assignment 1: Basic practice
Create an `index.html` file with three paragraphs. Create a `style.css` file and link it. Use an element selector to make all paragraphs blue.

## Assignment 2: Intermediate practice
Add a class of `special` to the second paragraph. Use a class selector in your CSS to make that specific paragraph red.

## Assignment 3: Real-world practical task
Create a small article page (`index.html`) and style it (`style.css`).
1. HTML: An `<h1>` title with an ID of `main-heading`.
2. HTML: Two `<p>` tags. Give the first one a class of `intro`.
3. CSS: Target the ID and change its color to dark slate gray (`darkslategray`).
4. CSS: Target the `intro` class and make its font size larger (e.g., `24px`).
5. CSS: Target all paragraphs and change their font family to sans-serif (`font-family: sans-serif;`).

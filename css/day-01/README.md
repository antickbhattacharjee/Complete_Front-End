# Day 01: Introduction to CSS & Selectors

## Learning Objectives:
- Understand what CSS is and how it interacts with HTML.
- Learn the three ways to add CSS to HTML (Inline, Internal, External).
- Master basic CSS selectors (Element, Class, ID).

## Expected Learning Outcome:
You will be able to link a stylesheet to an HTML document and apply basic styles to specific elements.

## Duration:
2 Hours

## Prerequisites:
- Completion of the HTML curriculum.

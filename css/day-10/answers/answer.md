# Day 10 Answer

## Explanation
This solution integrates all core CSS principles. 
- **Variables** are used for maintainability.
- **Flexbox** handles 1D alignment (Navbar, Hero centering, Footer).
- **Grid** handles the 2D layout of the features, easily adapting across breakpoints.
- **Transitions** provide a premium feel without hurting performance.

## Expected Output
A highly professional landing page. The header stays at the top when scrolling. The Hero section grabs attention. The features grid perfectly snaps from 1 to 2 to 3 columns depending on the window width. Hovering over cards or buttons feels smooth and interactive.

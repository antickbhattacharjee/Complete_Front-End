# Day 10 Assignment (Final Project)

## The Task: Business Landing Page
Create `index.html` and `style.css` in the `starter` folder.

Follow this exact structure:

1. **HTML Structure**
   - Standard HTML5 boilerplate.
   - Link Google Fonts (Inter) and your `style.css`.
   - `<header>` for the Navbar.
   - `<main>` containing two `<section>`s: `.hero` and `.features`.
   - `<footer>` for the copyright.

2. **CSS Variables & Reset**
   - Create variables for `--primary-color` and `--bg-light`.
   - Apply the universal reset.

3. **Navbar Implementation**
   - Flexbox, space-between. Sticky positioning.

4. **Hero Section Implementation**
   - Minimum height of `60vh`. Flexbox, center aligned vertically and horizontally. Add a nice background color or subtle gradient.

5. **Features Grid Implementation**
   - Create 3 `.feature-card` divs inside the `.features` section.
   - Use CSS Grid.
   - **Mobile**: 1 column.
   - **Tablet (`min-width: 768px`)**: 2 columns.
   - **Desktop (`min-width: 1024px`)**: 3 columns.

6. **Animations**
   - Add a smooth `transition` to the `.feature-card` so it lifts up (`translateY`) on hover.

# Day 09: Animations, Transitions & Transforms

## Learning Objectives:
- Use `transition` for smooth state changes (like hovering).
- Use `transform` to scale, rotate, and translate elements.
- Create keyframe animations (`@keyframes`) for complex, multi-step animations.

## Expected Learning Outcome:
You will be able to make a webpage feel dynamic and alive with micro-interactions and smooth visual effects.

## Duration:
2 Hours

## Prerequisites:
- CSS Selectors and Basic styling.

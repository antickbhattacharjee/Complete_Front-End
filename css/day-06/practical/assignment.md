# Day 06 Assignment

## Assignment 1: Basic practice
Create a `<div>` containing 3 buttons. Make the `<div>` a flex container. Use `justify-content` to space them evenly across the screen.

## Assignment 2: Intermediate practice
Give the flex container a height of 200px and a background color. Use `align-items: center;` to perfectly vertically center the buttons inside that 200px box.

## Assignment 3: Real-world practical task
Create a proper Navigation Bar.
1. Create `nav.html` and `style.css`.
2. HTML: `<header>` -> `<div class="logo">` and `<nav>` -> `<ul>` -> 3 `<li>` links.
3. CSS: Make the `<header>` a flex container. Use `space-between` so the logo is on the far left and the nav is on the far right. Vertically center them.
4. CSS: Make the `<ul>` a flex container too, so the links sit side-by-side. Use `gap: 20px;` to space the links.
5. Make it look professional (background color, text color, remove underlines from links).

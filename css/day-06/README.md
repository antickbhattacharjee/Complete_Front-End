# Day 06: Flexbox Fundamentals

## Learning Objectives:
- Understand the Flexbox 1-dimensional layout model.
- Master Flex Containers vs Flex Items.
- Use `justify-content` and `align-items` to align elements effortlessly.
- Use the `gap` property for spacing.

## Expected Learning Outcome:
You will be able to build complex alignment layouts (like Navigation bars and Side-by-side cards) cleanly and easily without using hacks like floats.

## Duration:
3 Hours

## Prerequisites:
- Display and Box Model knowledge.

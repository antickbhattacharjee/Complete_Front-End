# Day 08: Responsive Web Design

## Learning Objectives:
- Understand the concept of Mobile-First design.
- Use Media Queries (`@media`) to change CSS at different screen sizes.
- Utilize relative units (`%`, `vw`, `vh`, `rem`) instead of fixed `px`.

## Expected Learning Outcome:
You will be able to make websites look perfect on mobile phones, tablets, and large desktop monitors.

## Duration:
3 Hours

## Prerequisites:
- Flexbox and Grid.

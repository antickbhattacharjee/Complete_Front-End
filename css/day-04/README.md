# Day 04: The Box Model

## Learning Objectives:
- Completely understand the CSS Box Model (Content, Padding, Border, Margin).
- Use `box-sizing: border-box` to fix width calculations.
- Implement spacing between elements effectively.

## Expected Learning Outcome:
You will be able to precisely control the size of HTML elements and the exact spacing between them, avoiding common layout breaking issues.

## Duration:
2.5 Hours

## Prerequisites:
- CSS Selectors, Colors, and Borders.

# Day 04 Assignment

## Assignment 1: Basic practice
Create a `<div>` with the text "Hello". Give it a red background. Give it 50px of padding on all sides. Notice how the red background grows.

## Assignment 2: Intermediate practice
Add 50px of margin to your div. Notice how the box moves away from the edges of the screen, but the red background does not grow.

## Assignment 3: Real-world practical task
Create a neat "Pricing Card" component.
1. Create `card.html` and `style.css`.
2. In your CSS, add the Universal Reset (margin 0, padding 0, box-sizing border-box).
3. Create a `.card` div. Give it a width of `300px`, `margin: 50px auto;` (to center it), a light gray background, and a 1px solid border.
4. Give the `.card` `20px` of padding.
5. Inside the `.card`, add an `<h2>` for the plan name, an `<h1>` for the price, and a `<p>` for the description.
6. Use margin-bottom on the headings to space them out vertically.

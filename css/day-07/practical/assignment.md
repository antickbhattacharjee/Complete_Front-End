# Day 07 Assignment

## Assignment 1: Basic practice
Create a container with 4 child `<div>`s. Use CSS Grid to make them display as a 2x2 grid. Make the columns equal width using `1fr`.

## Assignment 2: Intermediate practice
Add a 5th `<div>` to the top of your HTML. Use `grid-column` to make it span across both columns so it looks like a header above the 2x2 grid.

## Assignment 3: Real-world practical task
Build a Photo Gallery Layout.
1. Create `gallery.html` and `style.css`.
2. Add a `.gallery` container.
3. Inside, add 6 `<div>`s with a class of `.photo`. Give them a background color so you can see them.
4. CSS: Make `.gallery` a grid with 3 equal columns (`repeat(3, 1fr)`) and a `gap` of 15px.
5. CSS: Target the *first* `.photo` (using a specific class or `:first-child`) and make it span 2 columns and 2 rows, creating a "featured image" effect.

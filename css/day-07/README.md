# Day 07: CSS Grid Layout

## Learning Objectives:
- Understand the Grid 2-dimensional layout model.
- Define grid templates (`grid-template-columns`, `grid-template-rows`).
- Position items precisely within the grid.
- Use the `fr` (fractional) unit.

## Expected Learning Outcome:
You will be able to build complex, magazine-style layouts and photo galleries with precise control over both rows and columns simultaneously.

## Duration:
3 Hours

## Prerequisites:
- Flexbox (Day 06) to understand parent/child layout relationships.

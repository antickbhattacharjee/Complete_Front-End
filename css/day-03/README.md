# Day 03: Typography & Fonts

## Learning Objectives:
- Control text size, weight, and alignment.
- Implement external web fonts using Google Fonts.
- Understand line-height and letter-spacing for readability.

## Expected Learning Outcome:
You will be able to make text look professional, readable, and perfectly aligned using modern web fonts.

## Duration:
2 Hours

## Prerequisites:
- CSS Selectors and Colors.

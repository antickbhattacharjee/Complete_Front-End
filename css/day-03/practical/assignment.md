# Day 03 Assignment

## Assignment 1: Basic practice
Create an `<h1>` and center it on the page using `text-align`. Force it to be ALL CAPS using `text-transform`.

## Assignment 2: Intermediate practice
Create a paragraph. Set its `line-height` to `1.8`, and make the `font-weight` bold (`700`).

## Assignment 3: Real-world practical task
Create a typography-focused mini article.
1. Go to Google Fonts. Select the **Roboto** font (weights 400 and 700). Link it in your HTML.
2. In CSS, apply `font-family: 'Roboto', sans-serif;` to the `body`.
3. Create an `<h1>` article title. Make it centered, dark blue, and weight 700.
4. Create two paragraphs of text. Give them a `font-size` of `18px`, a `line-height` of `1.6`, and a dark gray color (`#333333`).

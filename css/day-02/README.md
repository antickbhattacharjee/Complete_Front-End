# Day 02: Colors, Backgrounds & Borders

## Learning Objectives:
- Use Hexadecimal, RGB, and HSL color values.
- Apply background colors and background images.
- Use CSS borders (width, style, color) and border-radius to round corners.

## Expected Learning Outcome:
You will be able to add vibrant colors, imagery, and shaped elements to your webpage.

## Duration:
2 Hours

## Prerequisites:
- CSS Selectors (Day 01).

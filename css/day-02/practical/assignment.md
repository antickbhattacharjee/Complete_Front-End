# Day 02 Assignment

## Assignment 1: Basic practice
Create a `<div>` with a class of `box`. Using CSS, give it a background color using a HEX code, and text color using a Keyword (like `white`).

## Assignment 2: Intermediate practice
Add a 5px dashed blue border to your `.box`.

## Assignment 3: Real-world practical task
Create an "Alert Banner" component.
1. In HTML, create a `<div>` with class `alert-danger`. Inside, write "Error: Invalid Password!"
2. In CSS, style `.alert-danger`:
   - Background color: Light red/pink (`#ffe6e6`).
   - Text color: Dark red (`#cc0000`).
   - Border: 1px solid red.
   - Border Radius: 5px.
   - *Note: It will look cramped, but that's okay. We learn spacing (padding) in Day 04.*

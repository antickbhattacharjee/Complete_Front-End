# Day 05 Assignment

## Assignment 1: Basic practice
Create three `<div>` tags (which are block by default). Use CSS to change them to `display: inline-block;`. Observe them sitting side-by-side.

## Assignment 2: Intermediate practice
Create a button that says "Chat". Use `position: fixed`, `bottom: 20px`, and `right: 20px` to stick it to the bottom right corner of the screen, regardless of scrolling.

## Assignment 3: Real-world practical task
Create an image with a text overlay (Hero Banner).
1. Create `banner.html`.
2. Create a `<div class="hero">`.
3. Inside, add an `<img src="...">` and an `<h1>` with some text.
4. CSS: Set `.hero` to `position: relative;`.
5. CSS: Set the `<h1>` to `position: absolute;`. 
6. Use `top`, `left`, `transform`, and color to perfectly center the text over the image.

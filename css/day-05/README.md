# Day 05: Display & Positioning

## Learning Objectives:
- Understand the difference between `block`, `inline`, and `inline-block` display types.
- Master the CSS `position` property (`static`, `relative`, `absolute`, `fixed`, `sticky`).
- Use z-index to control stacking order.

## Expected Learning Outcome:
You will be able to break elements out of normal document flow to create sticky navigation bars and floating buttons.

## Duration:
3 Hours

## Prerequisites:
- The Box Model (Day 04).

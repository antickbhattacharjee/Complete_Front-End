# Day 04: Links, Images & Multimedia

## Learning Objectives:
- Create absolute and relative hyperlinks.
- Display images using the `<img>` tag and understand the importance of the `alt` attribute.
- Embed audio and video files.
- Create links that open in new tabs.

## Expected Learning Outcome:
You will be able to link multiple pages together and enrich your web pages with media content.

## Duration:
2 Hours

## Prerequisites:
- HTML Document structure and basic text formatting.

# Day 04 Assignment

## Assignment 1: Basic practice
Create an HTML file with three links:
1. An absolute link to your favorite website.
2. A relative link to another HTML file in the same folder.
3. An absolute link that opens in a new tab (`target="_blank"`).

## Assignment 2: Intermediate practice
Find an image URL on the internet (like a Wikipedia image) and display it on your page using the `<img>` tag. Make sure to include a descriptive `alt` attribute.

## Assignment 3: Real-world practical task
Create a "Favorite Band/Artist" fan page.
1. Create `fanpage.html`.
2. Add a main heading with the artist's name.
3. Below the heading, display a photo of the artist (using a web URL).
4. Write a short paragraph about them.
5. Create a link saying "Read more on Wikipedia" that links to their wiki page and opens in a new tab.
6. Make the artist's photo clickable, so clicking the photo also goes to their Wikipedia page.

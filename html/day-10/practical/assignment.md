# Day 10 Assignment (Final Project)

## The Task: Personal Profile Page
Create `index.html` inside the `starter` folder.

Follow this exact structure:

1. **Document Setup**
   - Standard HTML5 boilerplate. Title it "My Resume".

2. **Header Area**
   - Use `<header>`.
   - Add an `<h1>` with your name.
   - Add a `<nav>` with a `<ul>` containing 4 links: About, Skills, Education, Contact. (Link them to the respective IDs of the sections below).

3. **Main Content Area**
   - Wrap everything below the header in `<main>`.

4. **About Section**
   - `<section id="about">`
   - Add an `<h2>` "About Me".
   - Add a profile picture (`<img>`) with an `alt` attribute.
   - Add two paragraphs (`<p>`) describing your background and goals.

5. **Skills Section**
   - `<section id="skills">`
   - Add an `<h2>` "Technical Skills".
   - Create an unordered list (`<ul>`) of at least 5 skills (e.g., HTML, CSS, JavaScript, Git).

6. **Education Section**
   - `<section id="education">`
   - Add an `<h2>` "Education & Experience".
   - Create a table (`<table>`) with a border.
   - Headers should be: "Year", "Institution", "Degree/Role".
   - Add at least 2 rows of data.

7. **Contact Section**
   - `<section id="contact">`
   - Add an `<h2>` "Contact Me".
   - Create a `<form>`.
   - It needs: Name (text), Email (email), Message (textarea), and a Submit button.
   - All inputs must have associated labels.

8. **Footer Area**
   - Use `<footer>`.
   - Add a paragraph with a copyright symbol and the current year.

# Assets Folder

This folder contains images and other media files used in the HTML Mini Project.

## Images

- **profile.jpg**: Student profile/headshot image (150x150px recommended)
  - Replace this with an actual photo or a portrait placeholder
  - Recommended dimensions: 150px × 150px
  - Format: JPEG, PNG, or WebP

## How to Add an Image

1. Replace `profile.jpg` with your own image file
2. Keep the filename as `profile.jpg` or update the HTML `src` attribute to match your filename
3. Ensure the image is optimized for web (compressed to reduce file size)

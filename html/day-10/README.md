# Day 10: Complete HTML Mini Project

## 🎯 Learning Objectives
- Synthesize all HTML knowledge from Days 01–09
- Build a complete, semantic, accessible, and structured webpage from scratch
- Create a professional portfolio or resume page
- Apply proper HTML5 standards throughout

## 📊 Difficulty Level
**Practical Capstone** — Integrates all previous learning

## ⏱️ Estimated Duration
**3 hours** (0.5 hours planning + 2 hours building + 0.5 hours refinement)

## 📋 Prerequisites
- Completion of HTML Days 01–09
- Strong understanding of all HTML elements and structure

## 🔑 Core Topics
1. Semantic HTML structure (`<header>`, `<main>`, `<nav>`, `<section>`, `<footer>`)
2. Navigation menus
3. Text formatting (headings, paragraphs, emphasis)
4. Lists (ordered and unordered)
5. Tables with proper structure
6. Forms and input elements
7. Images with descriptive alt text
8. Links (internal anchors and external)
9. Meta tags and document metadata
10. Accessibility best practices throughout

## 📝 Project Deliverable
Create a **Personal Profile / Resume Webpage** (`index.html`) containing:
- A professional header with navigation
- An about section introducing yourself
- A skills section (using lists)
- An education/experience section (using tables)
- A contact form
- A footer with copyright information

## 🎓 Suggested Lesson Sequence
1. **Planning** (20 min): Sketch the page layout on paper or in a tool
2. **Structure** (15 min): Create the semantic HTML skeleton
3. **Content** (45 min): Add all text, headings, and sections
4. **Forms** (20 min): Build the contact form with proper labels
5. **Media** (15 min): Add profile image with descriptive alt text
6. **Navigation** (15 min): Create internal anchor links
7. **Accessibility Audit** (30 min): Check with automated tools and manual testing
8. **Final Review** (20 min): Validate HTML and test in browser

## ✅ Project Requirements
- [ ] Valid HTML5 boilerplate with proper DOCTYPE, lang, charset, viewport
- [ ] Semantic landmarks: `<header>`, `<main>`, `<section>`, `<footer>`
- [ ] Navigation menu with meaningful links
- [ ] Profile/bio section with image and descriptive alt text
- [ ] Skills section using `<ul>` or `<ol>`
- [ ] Education table with proper `<thead>`, `<tbody>`, and `<th>` tags
- [ ] Contact form with labels for all inputs
- [ ] Proper heading hierarchy (no skipped levels)
- [ ] Meaningful link text (not "click here")
- [ ] Passed W3C HTML validation
- [ ] All form fields properly labeled for screen readers

## 🎓 Expected Learning Outcome
You will have built a professional, accessible HTML webpage ready to be styled with CSS in the next curriculum. This project demonstrates mastery of:
- HTML5 semantic structure
- Form accessibility
- Image optimization and alt text
- Proper link anchoring
- Professional organization and hierarchy

## 📚 Quick Revision Checklist
- [ ] Document has proper HTML5 boilerplate
- [ ] All content is inside `<main>` or semantic landmarks
- [ ] All images have descriptive `alt` attributes
- [ ] All form fields have associated `<label>` tags
- [ ] Heading hierarchy is logical (no `<h1>` → `<h3>` jumps)
- [ ] All links have meaningful text
- [ ] Internal anchor links use `id` attributes correctly
- [ ] Table has `<thead>` and `<tbody>` sections
- [ ] Code is properly indented for readability
- [ ] HTML validates with W3C Validator

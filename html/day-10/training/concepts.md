# Complete HTML Mini Project

## 1. Concept Explanation
Today, there are no new concepts. Today is about **integration**. In the real world, you do not write isolated tags; you build complete documents. 
A professional webpage must have:
1. The correct HTML5 boilerplate.
2. Semantic structure (`<header>`, `<main>`, `<footer>`, etc.).
3. Accessible media (images with `alt` text).
4. Forms for user interaction.
5. Tabular data where appropriate.

## 2. Project Requirements
You are going to build a **Personal Profile / Resume** webpage.

It must contain:
- A header with your name and a navigation menu linking to `#about`, `#skills`, `#experience`, and `#contact`.
- A profile picture.
- A summary about yourself.
- An unordered list of your skills.
- A table listing your educational or professional experience.
- A functional "Contact Me" form at the bottom.
- A footer with copyright info.

## 3. Common Mistakes to Avoid
- **Skipping heading levels**: Ensure you go `h1` -> `h2` -> `h3`.
- **Forgetting form labels**: Every `<input>` must have a linked `<label>`.
- **Div Soup**: Use `<section>` and `<article>` instead of `<div>`.

## 4. Best Practices
- Comment your HTML! Use `<!-- Section Name -->` to clearly separate different parts of your long document.
- Use internal anchor links (`href="#id"`) so clicking the navigation menu scrolls down the page.

## 5. Trainer Notes
- This is a lab day. Instructors should float around the room and review students' code, specifically checking for correct semantic tags and valid nested structures (like `<li>` inside `<ul>`).

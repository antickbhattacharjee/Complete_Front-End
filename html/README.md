# HTML Curriculum

Welcome to the **HTML Training Program**. This 10-day curriculum will take you from the very basics of web development to creating fully structured, semantic web pages.

## 🎯 Learning Outcomes
By the end of this module, you will be able to:
- Understand how the web works and the role of HTML.
- Construct well-formed, accessible HTML documents.
- Use text formatting, links, and media elements effectively.
- Build complex tables and interactive forms.
- Use HTML5 semantic elements to improve SEO and accessibility.

## 🛠️ Prerequisites
- Basic computer navigation skills.
- A text editor (VS Code recommended).

## 🚀 Projects
- **Day 10 Project**: You will build a complete "Personal Profile / Resume" webpage using all the HTML concepts learned across the 10 days, strictly adhering to semantic structure and accessibility guidelines.

## 📖 Recommended Progression
Ensure you complete the `practical/assignment.md` tasks every day before moving to the next topic. HTML is the skeleton of web development; a strong foundation here is crucial for CSS and JavaScript later.

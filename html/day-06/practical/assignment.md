# Day 06 Assignment

## Assignment 1: Basic practice
Create a simple form with a text input for a First Name, and a submit button. Ensure there is a working label.

## Assignment 2: Intermediate practice
Add to your form: A password input, and a dropdown (`<select>`) asking for the user's role (Admin, User, Guest).

## Assignment 3: Real-world practical task
Create a file named `contact.html`.
Build a complete "Contact Us" form. It must include:
1. Full Name (text input)
2. Email Address (email input)
3. Reason for contacting (radio buttons: Support, Sales, General)
4. A message area (`<textarea>`)
5. A checkbox to agree to the privacy policy
6. A Submit button
Ensure every input has a properly linked `<label>` and a `name` attribute.

# Day 06: Forms and Input Elements

## 🎯 Learning Objectives
- Construct interactive forms using the `<form>` tag
- Utilize various input types (text, email, password, radio, checkbox, date, etc.)
- Use `<label>` tags for proper form accessibility
- Create dropdown menus using `<select>` and `<option>`
- Build text areas and submit buttons
- Understand form attributes like `action`, `method`, `name`, and `id`

## 📊 Difficulty Level
**Intermediate** — Requires solid understanding of HTML structure

## ⏱️ Estimated Duration
**2.5 hours** (1.5 hours training + 1 hour practical exercises)

## 📋 Prerequisites
- Days 01–05 completed
- Understanding of HTML elements and attributes

## 🔑 Core Topics
1. The `<form>` element and key attributes
2. Text input types: text, email, password, number, date, tel
3. Checkbox and radio buttons
4. Dropdown selects with options
5. Text areas
6. Submit and reset buttons
7. Form labels and accessibility (critical!)
8. Input validation attributes (required, minlength, pattern)
9. Form grouping with `<fieldset>` and `<legend>`

## 📝 Files You Will Create
- `contact-form.html` — A contact form for collecting user messages
- `survey.html` — A multi-question survey form
- `registration.html` — A user registration form with various input types

## 🎓 Suggested Lesson Sequence
1. **Introduction** (10 min): Show real-world forms and discuss why they're important
2. **Form Basics** (20 min): Explain `<form>`, `<input>`, `<label>`, and attributes
3. **Input Types Demo** (20 min): Follow `training/demo/index.html`; show each input type
4. **Accessibility Focus** (15 min): Emphasize proper label association for screen readers
5. **Concept Study** (25 min): Work through `training/concepts.md`
6. **Practical Lab** (40 min): Complete `practical/assignment.md`
7. **Review & Testing** (10 min): Test forms in browser; check with accessibility tools

## ✅ Practical Assignment Summary
- **Assignment 1**: Create a simple contact form with name, email, and message fields
- **Assignment 2**: Build a survey with checkboxes and radio buttons
- **Assignment 3**: Construct a user registration form with validation attributes

## 🎓 Expected Learning Outcome
By the end of this day, you will:
- Understand how HTML forms collect user data
- Know which input type to use for different data (email vs. text, etc.)
- Understand the critical importance of form labels for accessibility
- Be able to create accessible, functional forms for real websites

## 📚 Quick Revision Checklist
- [ ] `<form>` wraps all form inputs; `action` and `method` attributes are important
- [ ] `<label for="id">` associates a label with an input (for accessibility)
- [ ] `<input type="email">` is for email; browsers validate the format
- [ ] `<input type="password">` masks text entry
- [ ] `<input type="checkbox">` allows multiple selections
- [ ] `<input type="radio">` allows only one selection in a group
- [ ] `<select>` creates dropdown menus with `<option>` tags
- [ ] `<textarea>` is for multi-line text
- [ ] `required` attribute makes a field mandatory
- [ ] Always associate labels with inputs using `for="id"` — this is **critical** for accessibility
- [ ] Screen readers announce labels to users; meaningful labels are essential

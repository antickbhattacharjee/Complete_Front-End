# Day 06: Forms and Input Elements

## Learning Objectives:
- Construct interactive forms using the `<form>` tag.
- Utilize various `<input>` types (text, email, password, radio, checkbox).
- Use `<label>` tags for accessibility.
- Create dropdown menus using `<select>` and text areas with `<textarea>`.
- Add submit buttons.

## Expected Learning Outcome:
You will be able to build comprehensive data-collection forms for user registration, contact pages, and surveys.

## Duration:
2.5 Hours

## Prerequisites:
- Knowledge of basic HTML elements.

# Day 02: HTML Document Structure

## Learning Objectives:
- Understand the standard HTML5 boilerplate.
- Learn about the `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>` tags.
- Understand the purpose of the `<title>` and `<meta>` tags.

## Expected Learning Outcome:
You will be able to set up a proper, industry-standard HTML document ready for development.

## Duration:
2 Hours

## Prerequisites:
- Day 01 completed.

# Day 02: HTML Document Structure

## 🎯 Learning Objectives
- Understand the standard HTML5 boilerplate
- Learn about DOCTYPE, html, head, and body tags
- Master meta tags (charset, viewport)
- Understand semantic structure and document hierarchy

## 📊 Difficulty Level
**Beginner** — Builds on Day 01

## ⏱️ Estimated Duration
**2 hours** (1.5 hours training + 0.5 hours practical exercises)

## 📋 Prerequisites
- Day 01 completed
- Comfortable with basic HTML tags

## 🔑 Core Topics
1. HTML5 doctype declaration
2. The root `<html>` element and `lang` attribute
3. The `<head>` section: metadata vs. visible content
4. Meta tags: charset, viewport, description
5. The `<title>` tag and browser tabs
6. The `<body>` section: visible content
7. Proper indentation and code formatting

## 📝 Files You Will Create
- `index.html` — A properly structured HTML5 document
- `about.html` — A page about yourself with correct structure
- Additional HTML pages with semantic structure

## 🎓 Suggested Lesson Sequence
1. **Review** (5 min): Recap Day 01 fundamentals
2. **Structure Walkthrough** (20 min): Explain each part of the HTML5 boilerplate
3. **VS Code Shortcut** (10 min): Show the `!` + Enter shortcut to auto-generate boilerplate
4. **Concept Study** (25 min): Follow `training/concepts.md`; dissect a real webpage
5. **Demo Analysis** (15 min): Examine `training/demo/index.html`
6. **Practical Lab** (35 min): Guide through `practical/assignment.md`
7. **Review** (10 min): Compare solutions

## ✅ Practical Assignment Summary
- **Assignment 1**: Create a proper HTML5 document with all required sections
- **Assignment 2**: Add content and verify structure in browser DevTools
- **Assignment 3**: Build a multi-page site with consistent structure

## 🎓 Expected Learning Outcome
By the end of this day, you will:
- Understand why proper HTML structure matters
- Be able to create a valid HTML5 document from scratch
- Know the purpose of each major element
- Understand the difference between head metadata and body content

## 📚 Quick Revision Checklist
- [ ] `<!DOCTYPE html>` declares HTML5 (always first, before opening `<html>` tag)
- [ ] `<html lang="en">` wraps all content; `lang` attribute is crucial for accessibility
- [ ] `<head>` contains **metadata** (title, charset, viewport, etc.) — not visible
- [ ] `<meta charset="UTF-8">` enables proper character encoding
- [ ] `<meta name="viewport" ...>` enables mobile responsiveness
- [ ] `<title>` appears in browser tab and is important for SEO
- [ ] `<body>` contains all **visible content**
- [ ] Proper indentation makes code readable
- [ ] W3C Validator can check if your HTML is valid

# Day 02 Assignment

## Assignment 1: Basic practice
Type out the full HTML5 boilerplate manually (without using VS Code shortcuts) to build muscle memory. Set the title to "Practice Page".

## Assignment 2: Intermediate practice
Inside the `<body>` of your practice page, add the content you created in Day 01 (headings and paragraphs).

## Assignment 3: Real-world practical task
Create a file named `index.html`. 
1. Generate the standard HTML5 structure.
2. Change the `<html lang="en">` attribute to your native language code (e.g., "es" for Spanish, "fr" for French) if applicable, or leave as "en".
3. Set the title to "My Portfolio".
4. In the body, write a professional introductory heading and a paragraph stating your career goals.

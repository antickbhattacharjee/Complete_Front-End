# Day 08: HTML Accessibility (a11y)

## Learning Objectives:
- Understand the principles of Web Accessibility (a11y).
- Use `alt` text properly.
- Understand and implement ARIA (Accessible Rich Internet Applications) attributes.
- Ensure forms and interactive elements are accessible.

## Expected Learning Outcome:
You will be able to write code that is usable by people with disabilities, particularly those using screen readers.

## Duration:
2 Hours

## Prerequisites:
- Semantic HTML (Day 07)
- Forms and Input Elements (Day 06)

# Day 08 Assignment

## Assignment 1: Basic practice
Write an accessible `<img>` tag for a photograph of a sunset, and an accessible `<img>` tag for a purely decorative line graphic.

## Assignment 2: Intermediate practice
Create an accessible search form. It needs a text input and a submit button that only contains a magnifying glass emoji (🔍). Use `aria-label` so a screen reader knows what the button does.

## Assignment 3: Real-world practical task
Create `accessible-page.html`.
You are given the following inaccessible HTML snippet:

```html
<div class="top">My Website</div>
<div class="menu">
    <span>Home</span> | <span>Settings</span>
</div>
<br><br>
<span class="title">Sign Up</span><br>
Email: <input type="text"><br>
<div class="submit-btn" style="cursor:pointer;">Send</div>
```

Your task is to rewrite this entirely using semantic HTML, proper form labels, and accessibility best practices.

# Day 01 Assignment

## Assignment 1: Basic practice
Create an HTML file and write three different headings (H1, H2, and H3) introducing yourself.

## Assignment 2: Intermediate practice
Below your headings, write a paragraph describing why you want to learn web development. 

## Assignment 3: Real-world practical task
Create a file named `welcome.html`. Inside it:
1. Put a main heading that says "My First Webpage".
2. Put a sub-heading that says "About HTML".
3. Write two paragraphs explaining what HTML is and what tags are.

*Do not worry about the `<head>` or `<body>` structure yet, just write the tags directly into the file.*

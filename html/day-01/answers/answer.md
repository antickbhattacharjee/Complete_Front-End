# Day 01 Answer

## Explanation
For these assignments, we focus on learning HTML tags. The core elements are heading tags (`<h1>` to `<h3>`) and the paragraph tag (`<p>`). We write these tags directly into an HTML file, and the browser interprets them correctly even without the full HTML boilerplate structure (which you will learn in Day 02).

## Assignment 1 Solution
Create three headings introducing yourself:
```html
<h1>My Name is Jane</h1>
<h2>Welcome to My Site</h2>
<h3>I am learning HTML</h3>
```

## Assignment 2 Solution
Add a paragraph with your motivation:
```html
<h1>My Name is Jane</h1>
<h2>Welcome to My Site</h2>
<h3>I am learning HTML</h3>
<p>I want to learn web development because I love creating beautiful, interactive websites that help people solve problems.</p>
```

## Assignment 3 Complete Solution
Create a file named `welcome.html` with:
```html
<h1>My First Webpage</h1>
<h2>About HTML</h2>
<p>HTML stands for HyperText Markup Language. It is used to create the structure of a website.</p>
<p>HTML uses tags to tell the browser how to display content. For example, we use headings and paragraphs.</p>
```

## Expected Output
When you open `welcome.html` in the browser, you should see:
- A large bold heading: "My First Webpage"
- A slightly smaller bold heading: "About HTML"
- Two lines of regular text describing HTML and tags

## Important Notes
- At this stage, you are writing tags directly into an HTML file. This works because browsers are forgiving and can interpret raw tags.
- In **Day 02**, you will learn the *proper* HTML5 document structure (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`) which is required for professional web development.
- The starter and demo files already show this structure so you can see what proper HTML looks like from the start.

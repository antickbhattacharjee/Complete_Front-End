# Day 01 Answer

## Explanation
For these assignments, we simply need to use the heading tags (`<h1>` to `<h3>`) and the paragraph tag (`<p>`).

## Complete Solution (Assignment 3)
```html
<h1>My First Webpage</h1>
<h2>About HTML</h2>
<p>HTML stands for HyperText Markup Language. It is used to create the structure of a website.</p>
<p>HTML uses tags to tell the browser how to display content. For example, we use headings and paragraphs.</p>
```

## Expected Output
When you open `welcome.html` in the browser, you should see a large bold heading, a slightly smaller bold heading, and two lines of regular text.

## Important Notes
At this stage, writing tags directly into an HTML file works, but in the next class, we will learn the *proper* document structure required for real websites.

# Day 01: HTML Fundamentals

## 🎯 Learning Objectives
- Understand what HTML is and its role in web development
- Create your first HTML document
- Learn HTML tags, elements, and attributes
- Open an HTML file in a browser and see it rendered

## 📊 Difficulty Level
**Beginner** — No prior knowledge required

## ⏱️ Estimated Duration
**2 hours** (1.5 hours training + 0.5 hours practical exercises)

## 📋 Prerequisites
- Basic computer knowledge (file management, text editor usage)
- A text editor ([VS Code](https://code.visualstudio.com/) recommended)
- A web browser (Chrome or Firefox)

## 🔑 Core Topics
1. What is HTML and its role in web development
2. HTML tags: opening tags, closing tags, and content
3. Attributes: providing additional information about elements
4. Common beginner tags: headings (`<h1>`-`<h3>`), paragraphs (`<p>`), links (`<a>`)
5. Semantic vs presentational markup

## 📝 Files You Will Create
- `first-page.html` — Your first HTML file
- `welcome.html` — A structured HTML document with headings and paragraphs

## 🎓 Suggested Lesson Sequence
1. **Introduction** (10 min): Show examples of websites and explain that HTML structures them
2. **Concept Study** (30 min): Follow `training/concepts.md`; demonstrate each example in the browser
3. **Live Demo** (20 min): Show `training/demo/index.html`; modify it in real-time
4. **Practical Lab** (40 min): Guide students through `practical/assignment.md` (all 3 assignments)
5. **Review** (10 min): Show solutions from `answers/solution/`; discuss common mistakes

## ✅ Practical Assignment Summary
- **Assignment 1**: Create three different headings introducing yourself
- **Assignment 2**: Add a paragraph explaining why you want to learn web development
- **Assignment 3**: Build a complete `welcome.html` page with headings and descriptive paragraphs

## 🎓 Expected Learning Outcome
By the end of this day, you will:
- Understand the basic structure of an HTML document
- Know how to write HTML tags correctly
- Be able to create a simple page with headings, paragraphs, and links
- Understand the importance of semantic HTML

## 📚 Quick Revision Checklist
- [ ] HTML = HyperText Markup Language (a *markup* language, not a programming language)
- [ ] Tags consist of: opening tag (`<tag>`), content, closing tag (`</tag>`)
- [ ] Attributes provide extra info (e.g., `href`, `src`, `title`)
- [ ] All tag names should be **lowercase**
- [ ] Attribute values must be quoted
- [ ] Heading hierarchy: `<h1>` (largest) → `<h6>` (smallest)
- [ ] The `<a>` tag creates links; `href` attribute specifies the URL
- [ ] Browsers are forgiving but always write proper HTML

# Day 01: HTML Fundamentals

## Learning Objectives:
- Understand what HTML is and its role in web development.
- Create your first HTML document.
- Understand elements and attributes.
- Open an HTML file in a browser.

## Expected Learning Outcome:
You will be able to write basic HTML tags, understand the syntax, and view your webpage in a browser.

## Duration:
2 Hours

## Prerequisites:
Basic computer knowledge.

## Tools Required:
- VS Code or any text editor
- Google Chrome or any modern web browser

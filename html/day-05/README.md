# Day 05: Lists and Tables

## Learning Objectives:
- Create Unordered (bulleted) and Ordered (numbered) lists.
- Understand how to nest lists.
- Build HTML tables using `<table>`, `<tr>`, `<th>`, and `<td>`.
- Use table attributes like `colspan` and `rowspan`.

## Expected Learning Outcome:
You will be able to display structured data clearly using lists and complex tables.

## Duration:
2 Hours

## Prerequisites:
- Basic HTML tags and document structure.

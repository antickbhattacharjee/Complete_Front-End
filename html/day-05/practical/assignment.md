# Day 05 Assignment

## Assignment 1: Basic practice
Create an ordered list `<ol>` of your top 3 favorite foods.

## Assignment 2: Intermediate practice
Create an unordered list of your hobbies. Inside one of those hobbies, nest an ordered list explaining the first 3 steps to get started with that hobby.

## Assignment 3: Real-world practical task
Create a file named `schedule.html`.
Create a weekly training schedule table for this HTML course.
1. The table should have a border so it's visible (`<table border="1">`).
2. The first row should be headers: "Day", "Topic", and "Status".
3. Add 3 rows of data representing Day 01, Day 02, and Day 03.
4. Fill in the data (e.g., Day 01, HTML Fundamentals, Completed).

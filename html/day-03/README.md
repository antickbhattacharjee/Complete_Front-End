# Day 03: Text & Formatting

## Learning Objectives:
- Master all 6 levels of HTML headings.
- Format text using bold, italics, strong, and emphasis tags.
- Create line breaks and horizontal rules.
- Understand the difference between visual formatting and semantic formatting.

## Expected Learning Outcome:
You will be able to format articles and text-heavy webpages properly using standard HTML tags.

## Duration:
2 Hours

## Prerequisites:
- Day 02 completed.

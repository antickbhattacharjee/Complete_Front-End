# Day 03 Assignment

## Assignment 1: Basic practice
Write an HTML document containing all 6 levels of headings.

## Assignment 2: Intermediate practice
Write a paragraph about your favorite movie. Make the title of the movie bold (`<strong>`) and make your favorite quote from the movie italic (`<em>`).

## Assignment 3: Real-world practical task
Create a file named `article.html`.
Create a news article structure:
1. Include a standard HTML boilerplate.
2. Use an `<h1>` for the article headline.
3. Add a `<hr>` below the headline.
4. Write two paragraphs of news content. 
5. Inside the paragraphs, use `<strong>` to highlight key facts (like dates or names).
6. Provide a dummy physical address at the bottom, using `<br>` to format the address onto multiple lines.

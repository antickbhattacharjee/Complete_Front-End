# Day 07: Semantic HTML

## Learning Objectives:
- Understand the difference between generic tags (`<div>`, `<span>`) and semantic tags (`<header>`, `<footer>`, `<article>`).
- Use HTML5 semantic elements to structure a webpage layout.
- Understand the SEO and accessibility benefits of semantic HTML.

## Expected Learning Outcome:
You will be able to structure modern webpage layouts that search engines and screen readers can easily understand.

## Duration:
2 Hours

## Prerequisites:
- Knowledge of basic HTML tags, links, and images.

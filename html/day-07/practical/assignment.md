# Day 07 Assignment

## Assignment 1: Basic practice
Create an HTML document. Use semantic tags to create a `<header>` containing an `<h1>`, and a `<footer>` containing a `<p>` with a copyright notice.

## Assignment 2: Intermediate practice
Add a `<main>` section between the header and footer. Inside `<main>`, create an `<article>` with a heading and a paragraph.

## Assignment 3: Real-world practical task
Create `layout.html`.
Build the semantic skeleton for a complete blog homepage:
1. A Header with the blog title and a Navigation menu (Home, About, Contact).
2. A Main area containing:
   - A Section for "Latest Posts" containing two Articles (each with a title, date, and short description).
   - An Aside (sidebar) containing a short "About the Author" paragraph.
3. A Footer with a copyright notice.
*(Remember: Do not use CSS. It will look plain, but the structure will be perfect!)*

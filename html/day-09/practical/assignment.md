# Day 09 Assignment

## Assignment 1: Basic practice
Create an FAQ section using three `<details>` and `<summary>` blocks.

## Assignment 2: Intermediate practice
Go to YouTube, find a video, click Share -> Embed, and copy the `<iframe>` code. Paste it into your HTML document and ensure it renders.

## Assignment 3: Real-world practical task
Create `advanced.html`.
Build a small "Business Contact" page utilizing advanced tags:
1. Add a page heading.
2. Create an FAQ section using `<details>` about business hours and location.
3. Use an `<iframe>` to embed a Google Map of any famous landmark (e.g., the Eiffel Tower).
4. *(Bonus)* Use a native `<dialog open>` at the top of the body to act as a simulated "Welcome" popup.
